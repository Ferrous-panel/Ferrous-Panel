# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.5.x   | :white_check_mark: |
| < 2.5   | :x:                |

## Reporting a Vulnerability

Because FerrousPanel manages privileged operating system resources (firewall rules, web server configurations, system services, and root databases), security is our utmost priority.

If you discover a security vulnerability in FerrousPanel:
1. **DO NOT** disclose the issue publicly on GitHub issues or discussions.
2. Please report the issue via GitHub Private Vulnerability Reporting at:
   https://github.com/Ferrous-panel/Ferrous-Panel/security/advisories/new
   or email the security team at `security@ferrous-panel.org`.
3. Provide a detailed description, including steps to reproduce and any proof-of-concept exploit code.

We commit to acknowledging your report within 48 hours and providing regular status updates until a patch is released.
